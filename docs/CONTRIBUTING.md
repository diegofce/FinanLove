# CONTRIBUTING.md

## How to Contribute

FinanLove is a private project, but it follows professional open-source standards.

### Workflow

1. **Read `AGENTS.md` and `docs/ARCHITECTURE.md`.**
2. **Create a Feature Branch:** `feature/your-feature-name`.
3. **Follow the Layered Architecture:** Ensure your logic is in the right place.
4. **Write Tests:** No PR will be accepted without tests.
5. **Run Quality Checks:** Ensure Ruff, MyPy, and ESLint pass.
6. **Update Documentation:** If you change an API or a core process, update the relevant docs.
7. **Submit a Pull Request.**

### Code Style

- **Python:** Follow PEP 8 and Ruff defaults. Use strict type hints.
- **TypeScript:** Use strict mode. No `any`. Use functional components and hooks.
- **CSS:** Use Tailwind CSS for styling.
